# 突击战线

一个原创的横版跑射小游戏，使用原生 HTML、CSS 和 Canvas 绘制，部署到 GitHub Pages 后可以直接在浏览器中游玩。

## 玩法

- `A / D` 或方向键：移动
- `W / ↑ / 空格`：跳跃
- `J / K / Enter`：射击
- `P / Esc`：暂停
- 手机端：使用屏幕底部的触控按钮

游戏包含 3 个区域、不同类型敌人、首领战、连击、拾取物、音效、暂停和移动端适配。所有画面元素均为本项目原创代码绘制，仅致敬经典横版跑射玩法，不包含原作的图片、音乐、角色或关卡素材。

## 本地运行

这是纯静态页面，不需要构建工具：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。
